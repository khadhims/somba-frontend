# Design System — somba-web-ui

Extracted from the actual codebase (`src/assets/sass/**`, `src/components/**`, `src/layouts/default-layout/**`). This is a **Bootstrap 5 + KeenThemes SCSS** admin theme — there is no Tailwind config in this project. All values below are copied from source, not invented.

Source of truth:
- `src/assets/sass/core/components/_variables.scss` — Bootstrap/KeenThemes variables
- `src/assets/sass/core/components/_variables-dark.scss` — dark mode overrides
- `src/assets/sass/components/_variables.override.scss` — this project's overrides
- `src/assets/sass/layout/_variables.scss` — header/aside/content layout
- `src/assets/sass/core/components/_root.scss` / `layout/_root.scss` — CSS custom properties (`--bs-*`)

## Color Palette

## Typography

- **Font family**: `Inter, Helvetica, sans-serif` — loaded from Google Fonts in `index.html`:
  `https://fonts.googleapis.com/css?family=Inter:300,400,500,600,700`
- **Root font size**: `13px` desktop/tablet-lg, `12px` on mobile (`$root-font-size` in `layout/_variables.scss`) — the whole `rem` scale is relative to this, not the browser default 16px.
- **Base font size**: `1rem` (≈13px at root)

### Font weights available
`300` (light), `400` (normal/base), `500` (semibold), `600` (bold — also default heading weight), `700` (bolder)

### Font size scale (`$font-sizes` map, relative to 13px root)
| Token | Multiplier | ≈px |
|---|---|---|
| `fs-sm` | ×0.95 | ~12.4px |
| `fs-base` | ×1 | 13px |
| `fs-lg` | ×1.075 | ~14px |
| `fs-xl` | ×1.21 | ~16px |
| `fs-6` (h6) | ×1.075 | ~14px |
| `fs-5` (h5) | ×1.15 | ~15px |
| `fs-4` (h4) | ×1.25 | ~16.25px |
| `fs-3` (h3) | ×1.35 | ~17.5px |
| `fs-2` (h2) | ×1.5 | ~19.5px |
| `fs-1` (h1) | ×1.75 | ~22.75px |
| `fs-2x` → `fs-7x` | ×2 → ×7 | 26px → 91px, large numeric/display stats |

Display headings (`$display-font-sizes`): `display-1` 5rem → `display-6` 2.5rem, weight `bolder` (700).

### Line heights
- Base `1.5`, small `1.25`, large `1.75`, xl `2`, xxl `2.25`
- Headings: `1.2`

### Heading color/weight
- `$headings-font-weight: 600`, `$headings-color: --bs-gray-900`

## Core UI Components

Components are plain **Vue 3 SFCs styled with Bootstrap utility classes + KeenThemes SCSS partials** (`src/assets/sass/core/components/*.scss`) — no CSS-in-JS, no Tailwind.

### Buttons (`core/components/_buttons.scss`, variables in `_variables.scss`)
- Base padding: `.775rem 1.5rem`, font-size `1.1rem`, weight `semibold (500)`, `box-shadow: none`
- Sizes: `.btn-sm` (padding `.55rem .75rem`), `.btn-lg` (`.825rem 1.75rem`)
- Border radius follows global `$border-radius` (0.475rem)
- Contextual variants generated from `$theme-colors` map: `btn-primary`, `btn-secondary`, `btn-success`, `btn-info`, `btn-warning`, `btn-danger`, `btn-dark`, `btn-light` — each has base/active/hover from the `-active` color map
- `_btn-secondary.scss` — project-specific secondary button tweak
- Custom: `btn-active-light-*`, `btn-color-*` KeenThemes light/flush variants exist in `core/components/buttons/` and `buttons_new/`

### Cards (`core/components/_card.scss`, `src/components/cards/*.vue`)
- `card-border-enabled: true`, border color `--bs-gray-200`, radius = `$border-radius-lg` (0.625rem)
- Padding: `card-py: 2rem`, `card-px: 2.25rem`; header height `70px`
- Shadow: `0px 3px 4px 0px rgba(0,0,0,.03)` (light), `none` (dark)
- Variants in `src/components/cards/`: `Card.vue` (modal-promo card with illustration + CTA), `Card1.vue`–`Card5.vue` (content variants), `ActivitySummaryCard.vue` (dashboard stat card)
- Dashboard/stat widgets live separately under `src/components/widgets/statsistics/Widget1.vue`–`Widget5.vue` — card + background shape image + title/value/description pattern used for KPI tiles

### Forms (`core/components/_forms.scss`, `core/components/forms/`)
- Input padding matches buttons: `.775rem 1rem`, font-size `1.1rem`, weight `semibold`
- Label: font-size `1.05rem`, weight `500`, color `--bs-gray-800`
- Two input styles: **outline** (default, border `--bs-gray-300`) and **solid** (`input-solid`, bg `--bs-gray-100`, focus bg `--bs-gray-200`) — used interchangeably across forms (e.g. camera form)
- Checkboxes/radios/switches: custom SVG-based check/indeterminate icons, checked state uses `--bs-primary`
- Floating labels supported (`form-floating`, height `3.75rem`)

### Navigation
- **Aside (sidebar)**: fixed dark navy (`$coal-500`) 265px sidebar regardless of light/dark theme, defined in `layouts/default-layout/components/aside/`, menu config in `layouts/default-layout/config/MainMenuConfig.ts`
- **Header**: 74px desktop / 55px mobile, white/coal-400 background with subtle shadow, `layouts/default-layout/components/header/`
- **Menu component** (`core/components/_menu.scss`): link padding `.65rem 1rem`, active/hover states use `--bs-primary` text on `--bs-gray-100` bg
- **Breadcrumbs**: active color `--bs-primary`, divider `--bs-gray-600`
- **Dropdowns** (`src/components/dropdown/Dropdown1.vue`–`4.vue`): white/body-bg background, big soft shadow `0 0 50px rgba(82,63,105,.15)`, radius = base radius

### Tables (`src/components/kt-datatable/KTDataTable.vue`)
- Cell padding `.75rem` (`.5rem` for `-sm`), striped/hover rows use `--bs-gray-100`, border color `--bs-border-color`
- Used for all list views (organizations, cameras, etc.)

### Modals (`src/components/modals/{forms,general,membership,wizards}`)
- Body padding `1.75rem`, radius = base radius, box-shadow `0 .25rem .5rem rgba(0,0,0,.05)`
- Organized by purpose: `forms/` (create/edit dialogs), `general/` (invite, confirm), `wizards/` (multi-step, e.g. `CreateAppModal.vue`), `membership/`

### Badges
- Padding `.325rem .5rem`, weight `bold (700)`, radius `$border-radius-sm`, sizes sm/base/lg (1.5rem/1.75rem/2rem)

### Other reusable pieces
- `src/components/DatePicker.vue`, `src/components/GlobalSearch.vue` (Ctrl+K palette), `src/components/CameraPlaybackModal.vue`, `src/components/ItemPerPage.vue`, `src/components/Notice.vue`, `src/components/FullScreenLoader.vue`

## Page Structure

Defined in `src/layouts/default-layout/DefaultLayout.vue`:

```
<div class="page d-flex flex-row">
  ├─ KTAside            → fixed 265px dark sidebar (nav menu), toggleable via asideEnabled
  └─ #kt_wrapper (flex-column)
       ├─ KTHeader       → 74px top bar (breadcrumbs/title, search, user menu)
       ├─ #kt_content
       │    └─ .container-fluid | .container-xxl
       │         └─ <router-view/>   ← page content renders here
       └─ KTFooter
</div>
+ global overlays (siblings of .page, mounted once):
   KTScrollTop, KTDrawerMessenger, KTActivivityDrawer,
   KTCreateApp modal, KTInviteFriendsModal, KTToolButtons,
   KTHelpDrawer, GlobalSearch (Ctrl+K)
```

- Content width toggles between fluid (edge-to-edge) and constrained `container-xxl` (max 1320px) per-route via `contentWidthFluid` config.
- Sidebar, header and footer background/shadow all swap via the light/dark `@include color-mode()` mixin — no per-component dark-mode CSS needed, just use the `--bs-*` vars.
- Routes are organized under `src/views/{apps,organization,controlplane}/` matching the sidebar menu groups in `MainMenuConfig.ts`.

## Practical notes for new UI work

1. **Always reference `var(--bs-*)`**, not hardcoded hex — dark mode is automatic via the color-mode mixin.
2. **Don't invent spacing/radius values** — use the `$spacers` steps (0.25rem increments) and the 5 defined radii (sm/base/lg/xl/2xl).
3. Root font-size is **13px**, not 16px — `1rem` ≠ 16px in this app. Use the `fs-*` utility classes rather than raw `rem`.
4. New buttons/badges/alerts should stay within the 8 theme colors (`primary/secondary/success/info/warning/danger/dark/light`) — each already has base/active/light/clarity/inverse variants generated.
5. Sidebar is **always dark** (`coal-500`) by design — don't theme it light.
